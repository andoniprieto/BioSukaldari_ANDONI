# BioSukaldari
ANDONI PRIETO RODRIGUEZ

Osagai Gutxiko Errezeta Osasuntsuak
## Sarrera: IKUTU BEHAR DA
Etxeko hozkailuan geratzen diren osagaiak sartu eta errezeta osasuntsuak eta jasangarriak gomendatzen dituen web-aplikazioa, elikagaiak ez xahutzeko.

Ezaugarri nagusiak:  Bilatzaile aurreratua, txartel bidezko Diseinua (cards UI), nutrizio-datuak eta pausoz pausoko gidak.

## 2. HELBURU DESBERDINAK
### 2.1 ONDORIOAK ETA KONPETENTZIA: 

Merkatua analizatu eta gero, ikusi da sektore honetan ez dagoela web aplikazio bat erabilgarria, nutrizio-kalitatea duena eta efizientea dena. Adibidez, SuperCook konplexua eta kargatua da, MyRealFood mugatuta dago errezetaren informazioarengatik eta Cookpad-en nutrizioaren kalitatea irregularra da. Beraz, BioSukaldari besteen web-aplikazioaren hobekuntzak bermatuko ditu edo irtenbide bat topatuko du.

  - https://www.supercook.com/#/desktop
  - https://cookpad.com/es
  - https://www.myrealfood.app/es/recipes
    

### 2.2 ERABILTZAILE MOTA:
Web-aplikazioak bi erabiltzaile profil nagusi izango ditu: unibertsitateko ikaslea eta langile lanpetua. Bi erabiltzaile hauek denbora gutxi dutelako sartzen dira BioSukaldarin. Horregatik, erraztasun eta sinpletasun osoa eskaini behar da, denbora ez galtzeko eta aplikazioa benetan erabilgarria eta eraginkorra izateko.
